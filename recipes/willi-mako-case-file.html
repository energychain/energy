Rezepte / Willi-Mako Klärfallakte

Willi-Mako Klärfallakte als JSON vorbereiten

Bevor ein MaKo-Fachcoach oder ein echter Prozesskontext ins Spiel kommt, hilft eine synthetische Fallakte: Ausgangsfrage, Marktrolle, Evidenzstatus, Annahmen, offene Rückfragen und No-Action-Grenzen stehen lesbar in einem JSON-Objekt.

Suchintention

Willi Mako Klärfall JavaScript Beispiel: Entwickler:innen und MaKo-Teams wollen sehen, wie ein Fall strukturiert werden kann, ohne echte Kundendaten, EDIFACT-Nachrichten oder Marktpartner-Kommunikation zu verwenden.

Public-safe Evidenz

Die öffentliche Willi-Mako-Seite empfiehlt synthetische oder anonymisierte Ersttests, Fallakten mit offenen Punkten und eine klare menschliche Entscheidungsgrenze. Dieses Rezept bildet nur diese Struktur lokal nach.

CTA

Wenn aus der Trockenübung ein echter Test wird: Felix Mertens kann einordnen, ob synthetischer Klärfall, browser-lokaler Sanitizer, Willi-Zugang oder CET-Token der passende nächste Schritt ist.

Prinzip

Das Beispiel ruft keinen Willi-Mako-Endpunkt und keine Cernion-API auf. Es sortiert eine künstliche Ausgangslage in eine Fallakte, die bewusst keine produktive Marktkommunikation auslöst.

node examples/willi-mako-case-file.js

Minimalbeispiel

const syntheticCase = {
  role: "Lieferant",
  processContext: "GPKE Klärfall / Stammdatenrückfrage",
  question: "Welche Rückfrage sollte vor einer Prozessantwort fachlich geklärt werden?",
  incomingSignal: { containsRealCustomerData: false, containsEdifactPayload: false }
};

console.log({
  publicSafe: true,
  noActionBoundaries: ["keine produktive Marktkommunikation", "Human Review"],
  suggestedHumanNextStep: "synthetische Fallakte intern prüfen"
});

Warum das nützlich ist

  • Fall statt Bauchgefühl: Das Team sieht, welche Evidenz fehlt und welche Annahmen gerade nur Arbeitshypothesen sind.
  • Sichere Datenkante: Öffentliche Beispiele bleiben synthetisch; echte Lieferstellen-, Kunden-, Marktpartner- oder EDIFACT-Daten gehören nicht in den Dry-Run.
  • Menschliche Grenze: Rückfragen, Kommunikation und fachliche Bewertung bleiben bewusst beim verantwortlichen Team.

Dieses Rezept ist technische Strukturierungshilfe. Es ist keine Rechtsberatung, keine Marktkommunikationsfreigabe, keine Prozess-, Frist-, Preis-, Vertrags- oder SLA-Zusage.
