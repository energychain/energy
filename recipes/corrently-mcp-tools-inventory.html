Corrently MCP Toolliste als JSON inventarisieren

Öffentliche MCP-Manifeste sind nützlich, aber sie sind noch kein Freifahrtschein für Agentenaufrufe. Dieses Rezept liest nur die Toolliste, fasst Eingabeschemata zusammen und markiert, wo Token, echte Daten oder fachliche Entscheidungen draußen bleiben.

Suchintention

Corrently MCP Tools JavaScript: Entwickler:innen möchten sehen, welche öffentlichen Energie-Tools existieren und welche Eingaben erwartet werden, bevor ein Agent tatsächlich ein Tool nutzt.

Public-safe Evidenz

Die öffentliche Corrently API stellt unter /v2.0/mcp/tools ein MCP-Toolmanifest bereit. Dieses Rezept liest nur Metadaten: Toolnamen, Beschreibungen und Input-Schemata.

CTA

Wenn aus der Toolliste ein kontrollierter CET-, MCP- oder Willi-Mako-Testpfad werden soll: Felix Mertens kann Demo, Test-Token und produktive Grenze fachlich einordnen.

Prinzip

Das Beispiel ruft keine Fachfunktion auf und sendet keinen Token. Es erstellt ein Manifest-Inventar für Review, Dokumentation und Agenten-Preflight.

node examples/corrently-mcp-tools-inventory.js

Minimalbeispiel

const endpoint = "https://api.corrently.io/v2.0/mcp/tools";
const manifest = await fetch(endpoint).then((response) => response.json());
const tools = manifest.tools.map((tool) => ({
  name: tool.name,
  required: tool.inputSchema?.required || [],
  hasOptionalToken: Boolean(tool.inputSchema?.properties?.token),
  boundary: "Manifest-Inventar; kein Tool-Aufruf"
}));
console.log(JSON.stringify({ source: endpoint, tools }, null, 2));

Warum das nützlich ist

  • Toolliste vor Toollauf: Agenten sehen zuerst, welche Eingaben ein Tool erwartet, statt sofort fachliche Aktionen zu starten.
  • Token-Hygiene: Optionale Token-Felder werden als Sicherheitskante sichtbar; das Beispiel gibt keine Secrets aus.
  • No-Action-Grenze: Marktdaten-, CO₂-, GSI- oder Solar-Tools bleiben in diesem Rezept reine Manifest-Metadaten.

Dieses Rezept ist technische Orientierung. Es ist keine Zusage zur API-Verfügbarkeit, keine Preis-, Lizenz-, Vertrags-, Rechts- oder Integrationsaussage und ersetzt keine fachliche Prüfung vor produktiver Nutzung.

Öffentliche Kontextquelle: Corrently MCP Toolmanifest.
