Willi-Mako-Frage als reproduzierbares Script stellen

Wenn eine Antwort später prüfbar sein soll, gehört die Frage in ein Script – nicht nur in einen Chat.

Für die aktuelle, lokal lauffähige Variante nutze den Willi-Mako Intent Dry-Run. Er dokumentiert Intent, Grenzen und No-Call-Gründe, bevor ein echter SDK- oder API-Aufruf vorbereitet wird.

node examples/willi-mako-intent-dry-run.js

Nutze keine echten Lieferstellen, Kundennamen, Mandantenfälle oder Vertragsdaten in Beispielanfragen. Für öffentliche Beispiele reichen abstrakte Fallbeschreibungen.

Open Source · JavaScript · Energiewirtschaft · gepflegt von STROMDAO. Praxisbeispiele verwenden synthetische Daten und ersetzen keine rechtliche Prüfung.
