Willi-Mako-Frage als reproduzierbares Script stellen

Wenn eine Antwort später prüfbar sein soll, gehört die Frage in ein Script – nicht nur in einen Chat.

import { WilliMako } from '@energychain/willi-mako-client';

const client = new WilliMako({ apiKey: process.env.WILLI_MAKO_API_KEY });
const question = 'Welche Prüfpunkte helfen bei einer unklaren UTILMD-Antwort?';

const result = await client.search(question, { context: 'synthetic-demo' });
console.log(JSON.stringify({ question, result }, null, 2));

Nutze keine echten Lieferstellen, Kundennamen oder Vertragsdaten in Beispielanfragen. Für öffentliche Beispiele reichen abstrakte Fallbeschreibungen.
