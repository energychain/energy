Evidence-Dossier als JSON-Status vorbereiten

Agentische Energiearbeit beginnt nicht mit der automatischen Entscheidung. Sie beginnt mit einer belastbaren Arbeitslage: Welche Evidenz liegt vor, welche Annahmen sind offen und wo bleibt ein menschlicher Prüfpunkt?

Suchintention

Evidence-Dossier JavaScript: ein kleines, lokales Muster für Teams, die Fachfragen erst als prüfbaren Status erfassen möchten, bevor ein Tool oder eine Entscheidung ins Spiel kommt.

Public-safe Evidenz

Die Cernion-Timeline vom 1. September 2026 formuliert die öffentliche These, dass agentische Arbeit zuerst eine belastbare Evidenzlage braucht. Das CET-README beschreibt Dossiers, Evidenz, Gaps und HITL-Grenzen als Kernmuster.

CTA

Wenn aus dem Muster ein kontrollierter Integrationspfad werden soll: Felix Mertens kann die fachliche Einordnung übernehmen.

Prinzip

Das Beispiel erzeugt aus synthetischen Daten eine kleine Statuskarte. Es zählt Evidenz, listet offene Annahmen und gibt bewusst nicht entscheidungsreif zurück, solange Prüfpunkte fehlen.

node examples/evidence-dossier-status.js

Minimalbeispiel

const dossier = {
  id: "ED-001",
  thema: "Synthetische Netzanschluss-Prüffrage",
  evidenzen: [
    { id: "EV-1", quelle: "synthetisches-formular", status: "vorhanden" },
    { id: "EV-2", quelle: "annahmen-notiz", status: "offen" }
  ],
  annahmen: [
    { id: "A-1", text: "Beispielwert gesetzt", status: "prüfen" }
  ]
};

const openEvidence = dossier.evidenzen.filter((item) => item.status !== "vorhanden");
const openAssumptions = dossier.annahmen.filter((item) => item.status !== "bestätigt");

console.log({
  dossierId: dossier.id,
  decisionReadiness: openEvidence.length || openAssumptions.length
    ? "nicht-entscheidungsreif"
    : "reviewbereit",
  openEvidence: openEvidence.map((item) => item.id),
  openAssumptions: openAssumptions.map((item) => item.id)
});

Warum das nützlich ist

  • Prüfbar: Quellenstatus und Annahmen werden als Daten geführt, nicht nur als Fließtext.
  • LLM-sicherer: Ein Agent kann auf offene Evidenz verweisen, statt fehlende Fakten zu ergänzen.
  • Governance-tauglich: Das Ergebnis bleibt ein Arbeitsstand und keine automatische Zusage.

Dieses Rezept ist technische Orientierung mit synthetischen Daten. Es ist keine Rechtsberatung, keine Netzanschluss-, Vertrags- oder Prozesszusage und ersetzt keine fachliche Prüfung.
