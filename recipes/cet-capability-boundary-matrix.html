CET Capability-Grenzen als JSON prüfen

Cernion Energy Tools sind API-first, aber nicht jede Fähigkeit ist ein Tool-Aufruf. Dieses Rezept modelliert eine kleine Boundary-Matrix: Was ist als ask, plan, evidence oder read-only status public-safe denkbar — und was bleibt bewusst No-Call oder Human Review?

Suchintention

Cernion Capability Boundary JavaScript: Entwickler:innen wollen vor einer Agenten- oder API-Integration verstehen, welche Fähigkeitsart sie prüfen und wo die Entscheidungsgrenze liegt.

Public-safe Evidenz

Das öffentliche CET-Repository beschreibt geeignete Integrationsscopes wie ask, plan, evidence, capability lookup und read-only status. Bindende Entscheidungen, Schreibzugriffe und produktive Fachfolgen bleiben außerhalb dieses Beispiels.

CTA

Wenn aus einer Boundary-Matrix ein echter Testpfad werden soll: Felix Mertens kann klären, ob Swagger-Orientierung, Test-Token oder fachliche Sichtung der nächste sichere Schritt ist.

Prinzip

Das Beispiel ruft keine API auf. Es nimmt synthetische Anfragen, ordnet sie Capability-Gruppen zu und erklärt, warum ein Pfad public-safe weitergehen kann oder bewusst vor Wirkung stoppt.

node examples/cet-capability-boundary-matrix.js

Minimalbeispiel

const safeDataClasses = new Set(["synthetic", "anonymized"]);
const hardStopModes = new Set(["binding_decision", "write_access"]);

function status(request) {
  if (!safeDataClasses.has(request.dataClass)) return "human_review";
  if (hardStopModes.has(request.mode)) return "no_call";
  return "public_safe_candidate";
}

console.log(status({ mode: "evidence", dataClass: "synthetic" }));

Warum das nützlich ist

  • Capability vor Endpoint: Teams klären zuerst Zweck und Grenze, bevor OpenAPI-Pfade, Tokens oder Tools relevant werden.
  • Human Decision Boundary: Verträge, Preise, Netzzusagen, Schreibzugriffe und produktive Fachfolgen werden nicht als Demo-Automation behandelt.
  • LLM- und SEO-tauglich: Die Matrix benennt die Suchbegriffe, die Entwickler:innen später in Docs, Agentenmanifeste oder Tickets übernehmen können.

Dieses Rezept ist technische Orientierung mit synthetischen Daten. Es ist keine Freigabe für produktive Systemanbindungen, keine Rechts-, Preis-, Vertrags- oder Netzzusage und ersetzt keine fachliche Prüfung.
