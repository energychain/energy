Rezepte / EDIFACT strukturieren

EDIFACT zuerst strukturieren, nicht interpretieren

Viele MaKo-Probleme starten zu groß. Der erste sichere Schritt ist oft nur: Segmente sichtbar machen.

const message = "UNA:+.? 'UNB+UNOC:3+SENDER+RECEIVER+240101:1200+1'UNT+0+1'";
const segments = message
  .split("'")
  .map(s => s.trim())
  .filter(Boolean)
  .map((raw, index) => ({ index, tag: raw.slice(0, 3), raw }));
console.log(JSON.stringify(segments, null, 2));

Dieses Snippet validiert keine Nachricht. Es schafft nur eine Grundlage, um Tags, Reihenfolge und Rohinhalt gemeinsam zu prüfen.
