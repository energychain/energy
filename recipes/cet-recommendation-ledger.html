Rezepte / CET-Empfehlungsledger

KI-Empfehlungen mit JavaScript nachvollziehbar zurückziehen

Eine neue, vorsichtigere Empfehlung genügt nicht, wenn der frühere Schritt scheinbar weiter gilt. Ein kleines lokales Ledger hält sichtbar, welche Empfehlung aktiv, abgeschwächt, zurückgezogen, ersetzt oder erledigt ist.

Suchintention

KI Empfehlung zurückziehen nachvollziehbar JavaScript: Wie bleibt ein Statuswechsel prüfbar, ohne alte Empfehlungen still aus der Ausgabe zu löschen?

Praktische Nutzenfrage

Kann ein Team erkennen, welcher Schritt nicht mehr gilt, warum er geschlossen wurde und welche Grenze oder Nachfolgeempfehlung jetzt maßgeblich ist?

Prüfgrenze

Das Script prüft nur den Zustandsvertrag synthetischer Einträge. Es beurteilt keine fachliche Richtigkeit und löst keine Aktion aus.

Lokaler Dry-Run

node examples/cet-recommendation-ledger.js

Das Beispiel prüft:

  • stabile und eindeutige Empfehlungs-IDs,
  • die Statuswerte active, weakened, withdrawn, superseded und done,
  • einen dokumentierten Grund für geschlossene oder veränderte Schritte,
  • eine aktive Nachfolgeempfehlung bei superseded,
  • den Schutz vor dem erneuten Auftauchen einer bereits zurückgezogenen Empfehlung.

Beispielausgabe

{
  "ledgerValid": true,
  "activeRecommendations": ["REC-SYN-003"],
  "proposalReview": [
    {
      "recommendationId": "REC-SYN-005",
      "accepted": false,
      "reason": "blocked_resurrection_of_REC-SYN-001"
    },
    {
      "recommendationId": "REC-SYN-006",
      "accepted": true,
      "reason": "no_closed_match"
    }
  ]
}

Ein kleiner, belastbarer Prüfpfad

  1. Jeder Empfehlung eine stabile ID und einen vergleichbaren Fingerprint geben.
  2. Statuswechsel nicht durch Löschen, sondern durch neuen Status, Zeitpunkt und Grund dokumentieren.
  3. Bei einer Ersetzung die Nachfolge-ID explizit verknüpfen.
  4. Nur aktive Empfehlungen in Arbeits- oder Übergabelisten übernehmen.
  5. Zurückgezogene oder ersetzte Schritte beim erneuten Vorschlag blockieren und menschlich prüfen.

Ein konsistentes Ledger macht den Verlauf sichtbar, beweist aber weder die fachliche Qualität der Empfehlung noch Berechtigung, Freigabe, Compliance oder Produktivreife.

Public-safe Evidenz

Der öffentliche CET-Commit „recommendation ledger with explicit retraction“ beschreibt stabile IDs, explizite Statuswerte und die Regel, dass zurückgezogene oder ersetzte Empfehlungen nicht still wiederkehren. Dieses Rezept abstrahiert den Zustandsvertrag in ein lokales Beispiel mit ausschließlich synthetischen Daten.
